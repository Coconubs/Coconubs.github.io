# Cobblemon PE, Bedrock: có bản cho Minecraft PE không?

Không. Cobblemon chỉ có cho Minecraft Java Edition. Các gói "Cobblemon PE", "Cobblemon Bedrock" hay "Cobblemon MCPE Việt hoá" trên mạng là addon người khác làm lại cho Bedrock, không phải của nhóm làm Cobblemon.
{: .fs-5 .fw-300 }

## Cobblemon chạy trên bản Minecraft nào

| Bản Minecraft | Cobblemon chính thức |
|---|---|
| Java Edition trên Windows, macOS, Linux | Có, qua Fabric hoặc NeoForge |
| Java Edition trên Android, chạy bằng launcher Java | Chạy được nếu máy đủ mạnh |
| Bedrock, Pocket Edition (PE) trên điện thoại, Windows, máy console | Không |

Cobblemon tải ở Modrinth hoặc CurseForge. Ngày 11/11/2026, bản mới nhất trên Modrinth là Cobblemon 1.8.4 cho Minecraft 1.21.1, ra ngày 27/10/2026.

## Addon "Cobblemon PE" là gì

Trên các trang addon Minecraft PE có nhiều gói mang tên Cobblemon, có cả bản Việt hoá. Đó là addon Bedrock lấy ý tưởng từ Cobblemon:

- Không phải của nhóm Cobblemon. Pokémon, giao diện và cách chơi khác bản Java.
- Không vào được server Cobblemon chạy Java như Coco Cobblemon, vì server cần máy bạn có đúng mod Cobblemon.
- Chỉ tải ở trang bạn tin được. Trang addon lạ hay gắn quảng cáo hoặc file giả.

## Muốn chơi Cobblemon trên điện thoại

Cách duy nhất để chơi Cobblemon thật trên điện thoại là chạy Minecraft Java Edition bằng một launcher Java:

- **Fold Craft Launcher (FCL), PojavLauncher:** chạy Java Edition trên Android, bạn tự cài Fabric và Cobblemon. Hợp để chơi một mình hoặc vào server tự chọn.
- **CocoLauncher Android:** bản thử nghiệm, chỉ để vào server Coco Cobblemon. Launcher tự cài gói Coco Lite khoảng 125 mod, máy cần RAM từ 6 GB, nên có 8 GB trở lên. Xem [Chơi Cobblemon trên điện thoại](/cobblemon-dien-thoai/).
- **CocoLauncher iOS:** bản thử nghiệm cho iPhone, iPad, cũng chỉ để vào Coco Cobblemon. Cài qua SideStore, lần đầu cần máy tính khoảng 30 phút. Xem [Cobblemon trên iPhone, iPad](/cobblemon-ios/).

## Người chơi PE vào server Cobblemon được không

Server Cobblemon chạy Java Edition, nên app Minecraft PE không vào được. Nếu máy Android đủ mạnh, bạn có thể vào Coco Cobblemon (`coco.ultramc.co`, Minecraft Java 1.21.1) bằng CocoLauncher Android và chơi chung với người dùng máy tính. Thông tin server ở trang [Server Cobblemon Việt Nam](/server-cobblemon-viet-nam/).

## Hỏi nhanh

### Tải Cobblemon cho Minecraft PE ở đâu?

Không có bản chính thức cho PE. Gói mang tên Cobblemon cho PE là addon của người khác.

### Cobblemon PE vào được server Coco Cobblemon không?

Không. Coco Cobblemon là server Minecraft Java 1.21.1 chạy Cobblemon 1.7.3 cùng bộ mod riêng, phải vào bằng CocoLauncher (xem [Tải CocoLauncher](/cocolauncher/)).

### "Cobblemon PE Việt hoá" (file mcaddon) có phải Cobblemon không?

Không. Đó là addon Bedrock người khác làm lại, không phải của nhóm Cobblemon và không vào được server Cobblemon chạy Java. Cobblemon thật trên Minecraft Java đã có sẵn tiếng Việt: bản 1.7.3 dịch khoảng 60% số khoá, bật trong Options, Language. Xem [Cobblemon Việt hoá](/cobblemon-viet-hoa/).

### Minecraft PE có Pokémon không?

Có vài addon Pokémon cho Bedrock do cộng đồng làm. Còn Cobblemon và Pixelmon là mod cho Java Edition, xem [Chơi Pokémon trong Minecraft](/pokemon-trong-minecraft/).
