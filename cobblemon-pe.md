# Cobblemon PE, Bedrock: có bản cho Minecraft PE không?

Trả lời ngắn: Cobblemon chính thức chỉ có cho Minecraft Java Edition, chạy qua Fabric hoặc NeoForge. Các gói "Cobblemon PE", "Cobblemon Bedrock" hay "Cobblemon MCPE Việt hoá" trên mạng là addon do người khác làm lại cho Bedrock, không phải bản của nhóm phát triển Cobblemon.
{: .fs-5 .fw-300 }

## Cobblemon chính thức chạy trên bản Minecraft nào

| Bản Minecraft | Cobblemon chính thức |
|---|---|
| Java Edition trên Windows, macOS, Linux | Có, qua Fabric hoặc NeoForge |
| Java Edition trên Android, chạy bằng launcher Java | Chạy được nếu máy đủ mạnh |
| Bedrock, Pocket Edition (PE) trên điện thoại, Windows, máy console | Không |

Cobblemon tải ở Modrinth hoặc CurseForge. Trên Modrinth, bản mới nhất lúc viết trang này là Cobblemon 1.8.4 cho Minecraft 1.21.1, ra ngày 27/10/2026.

## Addon "Cobblemon PE" là gì

Trên các trang addon cho Minecraft PE có nhiều gói mang tên Cobblemon, có cả bản Việt hoá. Đó là addon Bedrock làm theo ý tưởng của Cobblemon:

- Không phải bản của nhóm Cobblemon. Pokémon, giao diện và cơ chế khác bản Java.
- Không vào được server Cobblemon chạy Java, ví dụ Coco Cobblemon, vì server Java cần đúng mod Cobblemon ở máy người chơi.
- Chỉ tải ở trang bạn tin. Trang addon lạ hay gắn quảng cáo hoặc file giả.

## Muốn chơi Cobblemon trên điện thoại

Cách chơi Cobblemon thật trên điện thoại là chạy Minecraft Java Edition bằng một launcher Java, trên Android hoặc iPhone:

- **Fold Craft Launcher (FCL), PojavLauncher:** chạy Java Edition trên Android; bạn tự cài Fabric và Cobblemon. Hợp để chơi một mình hoặc vào server tự chọn.
- **CocoLauncher Android:** bản thử nghiệm chỉ để vào server Coco Cobblemon. Launcher tự cài gói Coco Lite khoảng 125 mod, cần RAM từ 6 GB, khuyên 8 GB trở lên. Xem [Chơi Cobblemon trên điện thoại](/cobblemon-dien-thoai/).
- **CocoLauncher iOS:** bản thử nghiệm cho iPhone, iPad, cũng chạy Java Edition và chỉ để vào server Coco Cobblemon. Cài qua SideStore, lần đầu cần máy tính khoảng 30 phút. Xem [CocoLauncher iOS](https://coconubs.github.io/CocoLauncher-iOS/).

## Server Cobblemon cho người chơi PE

Server dùng mod Cobblemon chạy Java Edition, nên app Minecraft PE không vào được. Nếu máy Android đủ mạnh, người chơi Việt có thể vào Coco Cobblemon (`coco.ultramc.co`, Minecraft Java 1.21.1) bằng CocoLauncher Android và chơi chung với người dùng máy tính. Thông tin server ở trang [Server Cobblemon Việt Nam](/server-cobblemon-viet-nam/).

## Hỏi nhanh

**Tải Cobblemon cho Minecraft PE ở đâu?**
Không có bản chính thức cho PE. Gói mang tên Cobblemon cho PE là addon của người khác, không phải Cobblemon.

**Cobblemon PE có vào được server Coco Cobblemon không?**
Không. Coco Cobblemon là server Minecraft Java 1.21.1 chạy Cobblemon 1.7.3 cùng bộ mod riêng, vào bằng CocoLauncher trên Windows, macOS hoặc Android.

**Minecraft PE có Pokémon không?**
Có vài addon Pokémon cho Bedrock do cộng đồng làm. Cobblemon và Pixelmon là mod cho Java Edition, xem [Chơi Pokémon trong Minecraft](/pokemon-trong-minecraft/).
