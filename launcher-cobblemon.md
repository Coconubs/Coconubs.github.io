# Launcher nào để chơi Cobblemon? Modrinth App, CurseForge, Prism Launcher, CocoLauncher

Cobblemon là mod cho Minecraft Java Edition, nên bạn cần một launcher cài được mod. Chọn launcher nào tuỳ bạn muốn chơi một mình, vào một server cụ thể hay chơi trên điện thoại.

## Từng launcher

**Modrinth App.** Có bản Windows, macOS, Linux. Tìm Cobblemon Official Modpack trong tab Modpacks, bấm Install, app tự tải đúng Minecraft, Fabric và các mod cần kèm. Hợp với người mới muốn chơi một mình. Các bước cụ thể ở trang [Cách tải Cobblemon](/cach-tai-cobblemon/).

**CurseForge App.** Có nhiều modpack Cobblemon do cộng đồng làm. Hợp nếu bạn vốn đã dùng CurseForge cho mod khác.

**Prism Launcher.** Mã nguồn mở, có bản Windows, macOS, Linux, nhập được modpack từ Modrinth và CurseForge. Hợp với người thích tự chỉnh từng bản cài; người mới sẽ thấy hơi nhiều tuỳ chọn.

**CocoLauncher.** Launcher riêng của server Coco Cobblemon, giao diện tiếng Việt, có bản Windows (Microsoft Store), macOS, và bản thử nghiệm cho Android, iPhone. Nhập tên, bấm **Chơi** là vào, launcher tự cài mọi thứ và tự cập nhật theo server. CocoLauncher chỉ dùng để vào Coco Cobblemon, không dùng để chơi một mình hay vào server khác. Tải ở trang [Tải CocoLauncher](/cocolauncher/).

## Vì sao modpack Cobblemon chính thức không vào được Coco Cobblemon

Trên Modrinth, Cobblemon Official Modpack [Fabric] bản mới nhất là 1.8.4, ra ngày 27/10/2026, đi cùng Cobblemon 1.8. Còn Coco Cobblemon đang chạy Cobblemon 1.7.3 cùng bộ mod riêng của server (menu tiếng Việt, Đấu Xếp Hạng, bang hội và nhiều mod khác). Bản Cobblemon và bộ mod trên máy bạn phải khớp với server, nên vào bằng modpack chính thức sẽ bị từ chối. CocoLauncher tải đúng bộ mod server đang dùng và tự cập nhật khi server thay đổi.

Server Cobblemon nào cũng vậy: trước khi vào, xem server chạy Minecraft và Cobblemon bản nào, có launcher hay modpack riêng không.

## Tự cài Cobblemon: lỗi hay gặp

- **Sai bản Java.** Minecraft 1.21.1 cần Java 21. Modrinth App, CurseForge App và Prism Launcher tự lo chuyện này; nếu tự cài Java thì chọn Java 21 bản 64-bit.
- **Thiếu Fabric API.** Cobblemon bản Fabric cần Fabric API. Cài qua modpack thì có sẵn rồi.
- **Lệch phiên bản với server.** Bản Minecraft, Cobblemon và các mod thêm nội dung phải khớp server.
- **Cấp RAM quá nhiều hoặc quá ít.** Chỉnh RAM cho game trong cài đặt của launcher, đừng cấp quá nửa RAM của máy. CocoLauncher mặc định cấp 2 đến 4 GB.
- **Dùng Minecraft Bedrock hay PE.** Cobblemon chỉ có cho Java Edition.

## Launcher Cobblemon trên điện thoại

Modrinth App, CurseForge App và Prism Launcher không có bản Android. Trên Android có vài launcher chạy được Minecraft Java Edition như Fold Craft Launcher (FCL) hay PojavLauncher, nhưng bạn phải tự cài Fabric và từng mod, máy cũng cần nhiều RAM.

CocoLauncher Android là bản thử nghiệm chỉ để vào Coco Cobblemon. Launcher tự cài gói Coco Lite khoảng 125 mod, máy cần RAM từ 6 GB, nên có 8 GB trở lên. Xem [Chơi Cobblemon trên điện thoại](/cobblemon-dien-thoai/).

iPhone, iPad cũng có CocoLauncher iOS bản thử nghiệm, chỉ để vào Coco Cobblemon, lần đầu cài cần máy tính. Xem [CocoLauncher iOS](https://coconubs.github.io/CocoLauncher-iOS/).
