# Cách chơi Pokémon trong Minecraft

Muốn bắt và đấu Pokémon trong Minecraft, bạn cần Minecraft **Java Edition** trên máy tính cộng với một mod Pokémon: **Cobblemon** hoặc **Pixelmon**, hai mod Pokémon được chơi nhiều nhất. Minecraft PE, Bedrock và bản máy console không chạy được hai mod này. Chơi một mình thì cài Cobblemon bằng Modrinth App; chơi cùng người Việt thì vào một server, ví dụ Coco Cobblemon (`coco.ultramc.co`), nơi launcher CocoLauncher tự cài đúng mod.
{: .fs-5 .fw-300 }

## Cần gì để chơi

- Minecraft Java Edition trên máy tính: Windows, macOS hoặc Linux.
- Một mod Pokémon: Cobblemon hoặc Pixelmon.
- Nếu chơi trên server: đúng bản Minecraft, đúng mod và bộ mod phụ mà server dùng.

Minecraft Bedrock, Minecraft PE trên điện thoại và bản máy console không chạy được Cobblemon hay Pixelmon. Các gói "Cobblemon PE" trên mạng là addon của người khác, xem [Cobblemon PE, Bedrock](/cobblemon-pe/).

## Cobblemon và Pixelmon khác gì

| | Cobblemon | Pixelmon (Pixelmon Reforged) |
|---|---|---|
| Bộ nạp mod | Fabric và NeoForge | Forge; bản cho Minecraft 1.21.1 dùng NeoForge |
| Bản cho Minecraft 1.21.1 | 1.7.3 ra ngày 31/01/2026; bản mới nhất trên Modrinth là 1.8.4 (27/10/2026) | Có, chạy trên NeoForge |
| Tải ở đâu | Modrinth hoặc CurseForge | reforged.gg hoặc CurseForge |

Cobblemon là mod mã nguồn mở, giấy phép MPL-2.0. Pixelmon là mod Pokémon có từ lâu hơn.

Hai mod không vào chung server được. Server Cobblemon cần máy bạn cài Cobblemon, server Pixelmon cần Pixelmon, và cả hai đều cần đúng phiên bản server đang chạy. Ví dụ server Coco Cobblemon chạy Cobblemon 1.7.3, nên máy cài Cobblemon 1.8 cũng không vào được.

## Chơi một mình hay vào server

- **Chơi một mình:** cài Cobblemon bản gốc bằng Modrinth App, các bước ở trang [Cách tải Cobblemon](/cach-tai-cobblemon/).
- **Chơi cùng người Việt:** vào một server Cobblemon. Server thường cần đúng bộ mod riêng, nên dùng launcher của server sẽ đỡ lỗi nhất. So sánh các launcher ở trang [Launcher nào để chơi Cobblemon](/launcher-cobblemon/).

## Server Pokémon cho người Việt: Coco Cobblemon

Coco Cobblemon là server Minecraft Java chơi Cobblemon 1.7.3 trên Minecraft 1.21.1, của cộng đồng người Việt, địa chỉ `coco.ultramc.co`. Vào game bằng CocoLauncher: nhập tên, bấm **Chơi**, launcher tự cài Java, Minecraft, Fabric và đúng bộ mod.

Trong server có Đấu Xếp Hạng tính Elo, BattleTower 555 tầng, Gym, Bang Hội Chiến, Raid Thế Giới và Legendary tích luỹ: server càng lâu chưa có Legendary thì tỉ lệ càng tăng. Menu và hướng dẫn bằng tiếng Việt. Xem thêm [Server Cobblemon Việt Nam: Coco Cobblemon](/server-cobblemon-viet-nam/) và [Tải CocoLauncher](/cocolauncher/).

## Hỏi nhanh

### Chơi Pokémon trong Minecraft cần gì?

Cần Minecraft Java Edition trên máy tính (Windows, macOS hoặc Linux) và một mod Pokémon: Cobblemon hoặc Pixelmon. Vào server thì cần đúng bản Minecraft và đúng bộ mod mà server đó dùng.

### Nên chơi Cobblemon hay Pixelmon?

Tuỳ nơi bạn muốn chơi: hai mod không vào chung server được, nên muốn vào server nào thì cài đúng mod của server đó. Chơi một mình thì mod nào cũng được; Cobblemon là mod mã nguồn mở, tải trên Modrinth, có hướng dẫn cài từng bước ở trang [Cách tải Cobblemon](/cach-tai-cobblemon/).

### Minecraft PE có chơi Pokémon được không?

Cobblemon và Pixelmon không chạy trên Bedrock hay PE. Trên Android, CocoLauncher Android là bản thử nghiệm chạy Java Edition, cần máy từ 6 GB RAM, xem [Chơi Cobblemon trên điện thoại](/cobblemon-dien-thoai/).

### Cài Pixelmon rồi vào server Cobblemon được không?

Không. Mỗi server chỉ nhận đúng mod và đúng phiên bản của nó.

### Có mất phí không?

Cobblemon và Pixelmon tải không mất phí. Tải CocoLauncher và vào server Coco Cobblemon cũng không mất phí.
