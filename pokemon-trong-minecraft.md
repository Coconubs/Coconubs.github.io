# Cách chơi Pokémon trong Minecraft

Muốn bắt và đấu Pokémon trong Minecraft, bạn cần Minecraft **Java Edition** trên máy tính và một mod Pokémon. Hai mod phổ biến nhất là **Cobblemon** và **Pixelmon**. Minecraft PE, Bedrock và bản console không chạy được hai mod này. Chơi một mình thì cài Cobblemon bằng Modrinth App. Muốn chơi chung với người Việt thì vào một server, ví dụ Coco Cobblemon (`coco.ultramc.co`), dùng CocoLauncher là có sẵn đúng mod.
{: .fs-5 .fw-300 }

## Cần gì

- Minecraft Java Edition trên máy tính: Windows, macOS hoặc Linux.
- Một mod Pokémon: Cobblemon hoặc Pixelmon.
- Nếu vào server: đúng bản Minecraft, đúng mod và bộ mod phụ mà server dùng.

Bedrock, PE trên điện thoại và bản console không chạy được Cobblemon hay Pixelmon. Mấy gói "Cobblemon PE" trên mạng là addon do người khác làm, xem [Cobblemon PE, Bedrock](/cobblemon-pe/).

## Cobblemon và Pixelmon khác gì

| Mục | Cobblemon | Pixelmon (Pixelmon Reforged) |
|---|---|---|
| Bộ nạp mod | Fabric và NeoForge | Forge; bản cho Minecraft 1.21.1 dùng NeoForge |
| Bản cho Minecraft 1.21.1 | 1.7.3 ra ngày 31/01/2026; bản mới nhất trên Modrinth là 1.8.4 (27/10/2026) | Có, chạy trên NeoForge |
| Tải ở đâu | Modrinth hoặc CurseForge | reforged.gg hoặc CurseForge |

Cobblemon là mod mã nguồn mở (giấy phép MPL-2.0). Pixelmon thì có từ lâu hơn.

Hai mod không chơi chung server được. Server Cobblemon cần bạn cài Cobblemon, server Pixelmon cần Pixelmon, và phải đúng phiên bản server đang chạy. Ví dụ Coco Cobblemon chạy Cobblemon 1.7.3, nên máy cài Cobblemon 1.8 cũng không vào được.

## Chơi một mình hay vào server

- **Chơi một mình:** cài Cobblemon bản gốc bằng Modrinth App, xem [Cách tải Cobblemon](/cach-tai-cobblemon/).
- **Chơi chung với người Việt:** vào một server Cobblemon. Server thường có bộ mod riêng, nên dùng launcher của server là ít lỗi nhất. So sánh các launcher ở trang [Launcher nào để chơi Cobblemon](/launcher-cobblemon/).

## Server Pokémon cho người Việt: Coco Cobblemon

Coco Cobblemon là server Cobblemon Việt Nam, chạy Cobblemon 1.7.3 trên Minecraft 1.21.1, địa chỉ `coco.ultramc.co`. Vào bằng CocoLauncher: nhập tên, bấm **Chơi**, launcher tự cài hết.

Server có Đấu Xếp Hạng tính Elo, BattleTower 555 tầng, Gym, Bang Hội Chiến, Raid Thế Giới và Legendary tích luỹ (server càng lâu chưa ra Legendary thì tỉ lệ càng tăng). Menu và hướng dẫn đều bằng tiếng Việt. Xem thêm [Server Cobblemon Việt Nam: Coco Cobblemon](/server-cobblemon-viet-nam/) và [Tải CocoLauncher](/cocolauncher/).

## Hỏi nhanh

### Nên chơi Cobblemon hay Pixelmon?

Tuỳ bạn muốn chơi ở đâu. Hai mod không chơi chung server được, nên muốn vào server nào thì cài đúng mod của server đó. Chơi một mình thì mod nào cũng được. Cobblemon mã nguồn mở, tải trên Modrinth, có hướng dẫn cài từng bước ở trang [Cách tải Cobblemon](/cach-tai-cobblemon/).

### Minecraft PE có chơi Pokémon được không?

Cobblemon và Pixelmon không chạy trên Bedrock hay PE. Trên Android có CocoLauncher Android, bản thử nghiệm chạy Java Edition, cần máy từ 6 GB RAM. Xem [Chơi Cobblemon trên điện thoại](/cobblemon-dien-thoai/).

### Cài Pixelmon rồi vào server Cobblemon được không?

Không. Server nào cũng chỉ nhận đúng mod và đúng phiên bản của nó.

### Có mất tiền không?

Cobblemon và Pixelmon tải miễn phí. CocoLauncher và server Coco Cobblemon cũng miễn phí.
