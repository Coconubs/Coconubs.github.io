# Sửa lỗi CocoLauncher

Các lỗi người chơi hay gặp và cách sửa. Không thấy lỗi của mình ở đây thì chụp màn hình gửi lên [Discord](https://discord.gg/hyspace).

## Windows
{: #windows }

| Lỗi | Cách xử lý |
|---|---|
| SmartScreen chặn file cài | Cài từ [Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H?cid=docs), hoặc [đối chiếu mã SHA-256](/cocolauncher/an-toan/#sha256) trước khi chạy file .exe |
| Bấm Chơi xong launcher báo game thoát mã 1 | Các ca từng gặp là do ổ đĩa đầy. Dọn bớt ổ rồi bấm Chơi lại |
| Game chậm hoặc văng | Tắt bớt app khác khi chơi |
| Vào server báo sai phiên bản hoặc thiếu mod | Mở lại CocoLauncher, bấm Chơi để tải bản mới. Đừng vào bằng launcher khác |

## macOS
{: #macos }

| Lỗi | Cách xử lý |
|---|---|
| Máy báo không xác minh được nhà phát triển | macOS 15 trở lên: vào System Settings > Privacy & Security, bấm **Open Anyway**. macOS 14 trở xuống: giữ Control, bấm vào app, chọn **Open** |
| Máy báo app "is damaged" | Tải lại file ở [trang tải](/cocolauncher/macos/). Vẫn bị thì hỏi trên Discord, đừng tự tắt bảo mật của macOS |
| Có bản mới mà launcher không tự cập nhật | Bản Mac không tự cập nhật: tải lại file .dmg, kéo đè vào Applications, dữ liệu game vẫn giữ nguyên |

## Android
{: #android }

| Lỗi | Cách xử lý |
|---|---|
| Giả lập bị văng | Cài file dành cho giả lập (GiaLap.apk), không dùng file điện thoại |
| Đen màn hình hoặc văng | Vào Cài đặt, mục **Bộ dựng hình** đang để Tự động thì đổi thử sang **LTW** hoặc **Zink** |
| Máy nóng, giật | Giảm độ phân giải xuống 50 đến 70% |
| Văng giữa chừng | Để Bộ nhớ cho game ở mức khuyên dùng, tắt bớt app khác |
| Tải file .apk đứng ở 100% | Kéo thanh thông báo xuống, Chrome đang chờ bạn bấm vào file |

## Vẫn lỗi?

Gửi ảnh lỗi lên [Discord](https://discord.gg/hyspace). Trên Android thì bấm thêm nút **Gửi log lỗi cho admin** trong Cài đặt.
