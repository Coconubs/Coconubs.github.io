# Sửa lỗi CocoLauncher

Lỗi người chơi hay gặp và cách sửa. Không thấy lỗi của bạn thì chụp màn hình gửi lên [Discord](https://discord.gg/hyspace).

## Windows
{: #windows }

| Lỗi | Cách xử lý |
|---|---|
| SmartScreen chặn file cài | Cài từ [Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H?cid=docs), hoặc [đối chiếu mã SHA-256](/cocolauncher/an-toan/#sha256) trước khi chạy file .exe |
| Launcher báo game thoát mã 1 ngay sau khi bấm Chơi | Ca đã gặp là ổ đĩa đầy. Dọn bớt ổ rồi bấm Chơi lại |
| Game chậm hoặc văng | Tắt bớt ứng dụng khác khi chơi |
| Vào server báo sai phiên bản hoặc thiếu mod | Mở lại CocoLauncher, bấm Chơi để tải bản mới. Đừng vào bằng launcher khác |

## macOS
{: #macos }

| Lỗi | Cách xử lý |
|---|---|
| Máy báo không xác minh được nhà phát triển | macOS 15 trở lên: System Settings > Privacy & Security, bấm **Open Anyway**. macOS 14 trở xuống: Control + click vào app, chọn **Open** |
| Máy báo app "is damaged" | Tải lại file từ [trang tải](/cocolauncher/macos/). Vẫn lỗi thì hỏi trên Discord, đừng tự tắt bảo mật của macOS |
| Có bản mới nhưng launcher không tự cập nhật | Bản Mac là vậy: tải lại .dmg, kéo đè vào Applications, dữ liệu game vẫn còn |

## Android
{: #android }

| Lỗi | Cách xử lý |
|---|---|
| Giả lập bị văng | Dùng file dành cho giả lập (GiaLap.apk), không dùng file điện thoại |
| Đen màn hình hoặc văng | Trong Cài đặt, mục **Bộ dựng hình** đang Tự động thì thử **LTW** hoặc **Zink** |
| Máy nóng, giật | Giảm độ phân giải xuống 50 đến 70% |
| Văng giữa chừng | Để Bộ nhớ cho game ở mức khuyên dùng, tắt bớt ứng dụng khác |
| Tải .apk đứng ở 100% | Kéo thanh thông báo xuống, Chrome đang chờ bạn bấm giữ file |

## Vẫn lỗi?

Gửi ảnh lỗi trên [Discord](https://discord.gg/hyspace). Trên Android dùng nút **Gửi log lỗi cho admin** trong Cài đặt.
