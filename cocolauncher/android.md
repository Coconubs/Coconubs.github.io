# Chơi Cobblemon trên điện thoại Android, iPhone

Cobblemon là mod cho Minecraft Java Edition, nên không cài được vào Minecraft PE hay Bedrock. Muốn chơi Cobblemon trên điện thoại, server Coco Cobblemon có **CocoLauncher Android**: bản thử nghiệm chạy Java Edition ngay trên máy Android và vào chung server với người chơi máy tính. iPhone, iPad có bản thử nghiệm riêng là [CocoLauncher iOS](#iphone-ipad).
{: .fs-5 .fw-300 }

[Tải CocoLauncher-Android.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android.apk){: .btn .btn-primary }

## Máy cần gì

- RAM từ 6 GB, khuyên dùng 8 GB trở lên.
- Chip tầm trung trở lên.
- Còn trống khoảng 2 GB.
- Lần đầu tải khoảng 400 MB, nên dùng Wi-Fi.

Máy yếu hơn có thể vẫn mở được, nhưng dễ giật hoặc văng khi vào chỗ đông người.

## Cài đặt

1. Tải [CocoLauncher-Android.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android.apk).
2. Mở file vừa tải. Máy hỏi thì cho phép trình duyệt cài ứng dụng không rõ nguồn gốc.
3. Mở CocoLauncher, nhập tên trong game, bấm **Chơi**.

Tải bằng Chrome mà thanh tải đứng ở 100% thì kéo thanh thông báo xuống: thường là Chrome đang chờ bạn xác nhận giữ file .apk.

Bản Android dùng gói **Coco Lite** khoảng 125 mod, nhẹ hơn bản máy tính nhưng vẫn vào chung server.

## Chơi trên giả lập MuMu, LDPlayer
{: #gia-lap }

Giả lập trên máy tính dùng bản riêng: [CocoLauncher-Android-GiaLap.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android-GiaLap.apk). Đừng cài file điện thoại vào giả lập. Nếu máy tính chạy được Windows thì nên dùng thẳng [CocoLauncher cho Windows](/cocolauncher/windows/), nhẹ và ổn định hơn chạy qua giả lập.

## iPhone, iPad

Có bản thử nghiệm **CocoLauncher iOS**, tải và xem hướng dẫn cài ở trang [CocoLauncher iOS](https://coconubs.github.io/CocoLauncher-iOS/). iPhone không cài app ngoài App Store trực tiếp được, nên cách cài dài hơn Android:

| Cần | Chi tiết |
|---|---|
| Máy | iPhone, iPad chạy iOS 14 trở lên. Khuyên máy 8 GB RAM (iPhone 15 Pro, 16, 17); máy 6 GB chơi được ở cấu hình Thấp |
| Máy tính | Windows hoặc Mac và cáp, dùng 1 lần khoảng 30 phút để cài SideStore và mở khoá RAM cho app |
| Tài khoản | Một Apple ID, nên dùng Apple ID phụ |
| Giữ app mở được | Cứ 7 ngày vào SideStore bấm Refresh. Quá hạn thì app không mở được cho tới khi Refresh |

Lần đầu app tải khoảng 1,5 GB, nên dùng Wi-Fi. Lỗi khi cài hoặc văng game: hỏi trên [Discord](https://discord.gg/hyspace), gửi kèm ảnh chụp và file `latestlog.txt` (app Tệp › CocoLauncher).

## Mẹo cho máy yếu

- Tắt các app chạy nền trước khi vào game.
- Giảm khoảng cách hiển thị trong cài đặt đồ hoạ.
- Máy nóng, giật: giảm độ phân giải trong cài đặt launcher xuống 50 đến 70%.
- Chơi lâu thì cắm sạc và để máy thoáng. Máy nóng sẽ tự hạ xung và giật hơn.

## Lỗi thường gặp trên Android

| Lỗi | Cách xử lý |
|---|---|
| Đen màn hình hoặc văng khi mở game | Trong Cài đặt, mục **Bộ dựng hình** đang Tự động thì thử **LTW** hoặc **Zink** |
| Văng giữa chừng | Để Bộ nhớ cho game ở mức khuyên dùng, tắt bớt ứng dụng khác |
| Giả lập bị văng | Dùng file dành cho giả lập, không dùng file điện thoại |

Vẫn lỗi: dùng nút **Gửi log lỗi cho admin** trong Cài đặt của launcher, rồi báo trên [Discord](https://discord.gg/hyspace).

## Hỏi nhanh

**Có server Cobblemon Việt nào vào được bằng điện thoại không?**
Có. Coco Cobblemon, server Cobblemon của cộng đồng người Việt (`coco.ultramc.co`, Minecraft Java 1.21.1), vào được trên Android bằng CocoLauncher Android và chơi chung với người dùng máy tính. Đây là bản thử nghiệm, cần RAM từ 6 GB.

**Dùng launcher Android khác như FCL hay PojavLauncher được không?**
Fold Craft Launcher (FCL) và PojavLauncher chạy được Minecraft Java Edition trên Android, nhưng bạn phải tự cài Fabric và từng mod cho đúng bản server. Server Coco Cobblemon cần đúng bộ mod riêng, nên dùng CocoLauncher Android để launcher tự cài.

**Chơi bằng Minecraft PE được không?**
Không. Cobblemon là mod cho Java Edition, Minecraft PE và Bedrock không vào được server. Gói "Cobblemon PE" trên mạng là addon của người khác, xem [Cobblemon PE, Bedrock](/cobblemon-pe/).
