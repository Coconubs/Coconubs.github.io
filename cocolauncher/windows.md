# Cài CocoLauncher trên Windows

Có hai cách cài, ra cùng một launcher. Máy cần Windows 10 hoặc 11 bản 64-bit.

## Cách 1: Microsoft Store (nên dùng)

1. Mở [CocoLauncher trên Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H?cid=docs). Nhà phát hành phải là **Coconubs**.
2. Bấm **Get** (hoặc **Tải**), chờ cài xong.
3. Mở CocoLauncher từ menu Start.

Bản Store đã được Microsoft kiểm tra nên không bị SmartScreen cảnh báo.

## Cách 2: file .exe

1. Tải [CocoLauncher-Setup.exe](https://github.com/Coconubs/cocolauncher-pack/releases/download/launcher/CocoLauncher-Setup.exe) từ GitHub của Coconubs.
2. Mở file. Windows có thể hiện "Windows protected your PC" vì file chưa ký số. Nếu bạn tải đúng link trên thì bấm **More info** rồi **Run anyway**. Còn lăn tăn thì dùng bản Store, hoặc [kiểm file trước](/cocolauncher/an-toan/#sha256).

## Lần đầu mở launcher

1. Nhập tên trong game: 3 đến 16 ký tự, gồm chữ không dấu, số hoặc dấu gạch dưới.
2. Bấm **Chơi**. Lần đầu phải tải khá nhiều nên hơi lâu, nhớ dùng mạng ổn định.
3. Game tự vào server. Đăng ký theo hướng dẫn trên màn hình, rồi gõ `/menu`.

Các bước sau khi vào game: [Cách vào server](/cach-vao-server/).

## Cập nhật

Mỗi lần bấm Chơi, gói mod tự cập nhật. Nếu trong game báo có bản launcher mới thì bấm **Cập nhật**, thoát game rồi mở lại CocoLauncher.

## Hỏi nhanh

### Nên cài từ Microsoft Store hay file .exe?

Nên dùng Microsoft Store, vì không bị SmartScreen chặn. File .exe vẫn là launcher đó, chỉ khác chỗ tải.

### Bị "Windows protected your PC" thì làm sao?

Bấm **More info** rồi **Run anyway**, miễn là bạn tải đúng link GitHub của Coconubs. Không yên tâm thì cài bản Store.
