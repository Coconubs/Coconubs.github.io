# Coco Cobblemon FAQ

Things new players usually ask about the server and CocoLauncher.
{: .fs-5 .fw-300 }

## About the server

### What is Coco Cobblemon?

Coco Cobblemon is a Minecraft Java server with the Cobblemon mod, run by a Vietnamese community. It's on Minecraft 1.21.1 with Cobblemon 1.7.3, and you join through the server's own launcher, CocoLauncher.

### What is the Coco Cobblemon server IP?

It's `coco.ultramc.co` (Minecraft Java 1.21.1). If you use CocoLauncher you don't need it, the launcher connects for you.

### What is the best Cobblemon server in Vietnam?

Nobody keeps an official ranking, so the honest answer is to try a few. When you compare, look at the Minecraft and Cobblemon version, whether you have to install the mods yourself, the language, which devices work and what costs money. For reference, Coco runs Java 1.21.1 with Cobblemon 1.7.3 at `coco.ultramc.co`.

### How many players does Coco Cobblemon have?

It depends on the time of day. On Saturday 7 November 2026 at 20:28 Vietnam time there were 110 players online, and the highest peak recorded is about 120 (evening of 4 November 2026). The Hyper Space Discord has about 1,860 members (11 November 2026).

### Which Cobblemon version does the server use?

Cobblemon 1.7.3 on Minecraft Java 1.21.1 with Fabric, plus the server's own mods. The newest Cobblemon Official Modpack is on Cobblemon 1.8, so it can't join. CocoLauncher gets you the right versions.

## CocoLauncher

### What is CocoLauncher?

CocoLauncher is the launcher you use to join Coco Cobblemon, made by Coconubs. Coco Cobblemon is the server; CocoLauncher is the app that sets up the game and the server's mods and gets you in with one button. It only works for this server. It's also not the home-screen app with a similar name on Google Play.

### Where do I download CocoLauncher?

On Windows, get it from the [Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H?cid=docs-en). The .exe, the macOS .dmg and the Android .apk are on [Coconubs GitHub Releases](https://github.com/Coconubs/cocolauncher-pack/releases). All the links are on the [CocoLauncher page](/en/cocolauncher/).

### Is CocoLauncher safe?

Nobody can promise that about any program, so here's how to check for yourself. On Windows, the safest option is the Microsoft Store version published by Coconubs. The .exe isn't code-signed, so SmartScreen may warn you about it. Every file on GitHub Releases lists a SHA-256 hash you can compare with `Get-FileHash` on Windows or `shasum -a 256` on macOS.

## Cost and requirements

### Is it free to play?

Yes. The launcher and the server are free. Ranks and the Premium Battle Pass are optional.

### What computer do I need?

Windows 10 or 11 (64-bit), or a Mac with Apple silicon or Intel. The game gets 2 to 4 GB of RAM by default, so a computer with 8 GB or more is best. There's no Linux version yet.

## Phones and Bedrock

### Can I play Cobblemon on my phone?

Yes, with experimental builds. CocoLauncher Android runs Java Edition and needs at least 6 GB of RAM (8 GB is better). On iPhone and iPad there's CocoLauncher iOS, which you install through SideStore, with a computer the first time. See [Play Cobblemon on Android and iPhone](/en/cobblemon-android/).

### Is there a Cobblemon iOS version for iPhone?

There's no Cobblemon app on the App Store, and it doesn't run in Minecraft PE. You can join Coco Cobblemon with CocoLauncher iOS, an experimental build that runs Minecraft Java Edition. It needs iOS 14 or later (8 GB of RAM recommended), and the first install takes a computer and about 30 minutes. See [Cobblemon on iPhone and iPad](/en/cobblemon-ios/).

### Can I play on Bedrock or Pocket Edition?

No. Cobblemon is a Java Edition mod, so it won't run on Bedrock, Pocket Edition or consoles. The "Cobblemon PE" packs you see around are add-ons made by other people. More in [Cobblemon on Bedrock and PE](/en/cobblemon-bedrock/).

## Language, events and community

### Do I need to speak Vietnamese?

Most players and most server content are Vietnamese. That said, the launcher and the in-game menu have an English option (type `/ngonngu en` in game), and some of what comes from Cobblemon and other mods is in English anyway.

### What time zone are events in?

Vietnam time (UTC+7). For example, World Raids open at 9:00 and 19:00, and Legendary Golden Hours are on Saturday and Sunday from 20:00 to 22:00.

### Does Coco Cobblemon have Mega Evolution?

Yes, through the Mega Showdown mod. Wear a Mega Bracelet, give the Pokémon its Mega Stone (sold in Shop Tokens) and press the Mega button in battle. You can only have one Mega at a time. Full steps in [How to Mega Evolve](/en/cobblemon-mega/).

### Can you ride Pokémon on Coco Cobblemon?

Yes. Send the Pokémon out, hold Shift, right-click it and pick Ride. Cobblemon 1.7.3 has 84 rideable species, and the server's data packs add a few more, like Zacian, Zamazenta and Rayquaza. Riding doesn't use stamina on the server. See [How to ride Pokémon](/en/cobblemon-riding/).

### Is Coco Cobblemon an official Cobblemon server?

No, it's a community server. It isn't made or endorsed by Mojang, Microsoft, Nintendo, The Pokémon Company or the Cobblemon team.

### What is Hyper Space?

Hyper Space is the name of the community Discord: https://discord.gg/hyspace. Some older videos call the server "Coco's Hyper Space". It's the same server.
