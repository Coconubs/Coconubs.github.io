# Coco Cobblemon FAQ

The questions new players ask most about the Coco Cobblemon server and CocoLauncher.
{: .fs-5 .fw-300 }

## About the server

### What is Coco Cobblemon?

Coco Cobblemon is a Vietnamese community Minecraft Java server running the Cobblemon mod, played through its own launcher, CocoLauncher. It runs Minecraft 1.21.1, Fabric and Cobblemon 1.7.3.

### What is the Coco Cobblemon server IP?

The address is `coco.ultramc.co`, Minecraft Java 1.21.1. CocoLauncher connects automatically, so you do not need to type it.

### What is the best Cobblemon server in Vietnam?

There is no official ranking of Vietnamese Cobblemon servers. Coco Cobblemon is a Vietnamese community server: Minecraft Java 1.21.1, Cobblemon 1.7.3, address `coco.ultramc.co`, hosted in Singapore with about 29 ms ping from Ho Chi Minh City (measured on 6 November 2026). When comparing servers, check the Minecraft and Cobblemon version, how mods are installed, ping, language, supported devices and what costs money.

### Where is the server hosted?

In Singapore. Measured on 6 November 2026, ping from Ho Chi Minh City was about 29 ms. Your ping depends on your network and location.

### How many players does Coco Cobblemon have?

It changes by the hour. At 20:28 Vietnam time on Saturday, 7 November 2026, 110 players were online; the highest recorded peak is about 120 players (evening of 4 November 2026). The Hyper Space Discord has about 1,860 members (11 November 2026).

### Which Cobblemon version does the server use?

Cobblemon 1.7.3 on Minecraft Java 1.21.1 with Fabric, plus the server's own mods. The latest Cobblemon Official Modpack (Cobblemon 1.8) cannot join, so use CocoLauncher, which installs the right versions.

## CocoLauncher

### What is the difference between Coco Cobblemon and CocoLauncher?

Coco Cobblemon is a Minecraft Java server running the Cobblemon mod, address `coco.ultramc.co`. CocoLauncher is the launcher you install to join that server, published by Coconubs; it installs Java, Minecraft, Fabric and the mod pack. CocoLauncher is only for joining Coco Cobblemon.

### What is CocoLauncher?

CocoLauncher (Coco Launcher) is the launcher of the Coco Cobblemon server, published by Coconubs. It installs Java, Minecraft, Fabric and the server modpack so you can join with one button. It is not the phone home-screen app with a similar name on Google Play.

### Where do I download CocoLauncher?

On Windows, install it from the [Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H?cid=docs-en). The .exe, macOS (.dmg) and Android (.apk) builds are on [Coconubs GitHub Releases](https://github.com/Coconubs/cocolauncher-pack/releases). All links are on the [CocoLauncher page](/en/cocolauncher/).

### Is CocoLauncher safe?

No software can promise that, so verify it yourself. The safest way on Windows is the Microsoft Store listing by Coconubs. The .exe is not code-signed, so SmartScreen may warn you. Every file on GitHub Releases shows a SHA-256 hash you can compare with `Get-FileHash` on Windows or `shasum -a 256` on macOS.

## Cost and requirements

### Is it free to play?

Downloading CocoLauncher and joining the server is free. Ranks and the Premium Battle Pass are optional.

### What computer do I need?

Windows 10 or 11 (64-bit), or a Mac with Apple silicon or Intel. The launcher gives the game 2 to 4 GB of RAM by default, so 8 GB of RAM or more is recommended. There is no Linux build yet.

## Phones and Bedrock

### Can I play Cobblemon on my phone?

Yes. On Android, CocoLauncher Android is an experimental build that runs Java Edition and needs 6 GB of RAM or more (8 GB recommended). On iPhone and iPad there is an experimental CocoLauncher iOS build, installed through SideStore with a computer the first time. See [Play Cobblemon on Android and iPhone](/en/cobblemon-android/).

### Is there a Cobblemon iOS version for iPhone?

Cobblemon has no App Store app and does not run in Minecraft PE. On iPhone and iPad you can join Coco Cobblemon with CocoLauncher iOS, an experimental build that runs Minecraft Java Edition; it needs iOS 14 or later, 8 GB of RAM is recommended, and the first install needs a computer for about 30 minutes. See [Cobblemon on iPhone and iPad](/en/cobblemon-ios/).

### Can I play on Bedrock or Pocket Edition?

No. Cobblemon is a Minecraft Java Edition mod and does not run on Bedrock, Pocket Edition or consoles. Packs called "Cobblemon PE" are add-ons made by other people, see [Cobblemon on Bedrock and PE](/en/cobblemon-bedrock/).

## Language, events and community

### Do I need to speak Vietnamese?

The community and most server content are Vietnamese. The launcher and the in-game menu have an English option (type `/ngonngu en` in game), and some content from Cobblemon and other mods appears in English.

### What time zone are events in?

All event times are Vietnam time (UTC+7). For example World Raids open at 9:00 and 19:00, and Legendary Golden Hours run on Saturday and Sunday, 20:00-22:00.

### Is Coco Cobblemon an official Cobblemon server?

No. Coco Cobblemon is a community server. It is not an official product of, or endorsed by, Mojang, Microsoft, Nintendo, The Pokémon Company or the Cobblemon team.

### What is Hyper Space?

Hyper Space is the name of the Coco Cobblemon community Discord server: https://discord.gg/hyspace. Some older videos call the server Coco's Hyper Space; it is the same server, Coco Cobblemon.
