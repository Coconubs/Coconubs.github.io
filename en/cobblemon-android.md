# Play Cobblemon on Android and iPhone

There's no official Cobblemon phone app, and it doesn't run in Pocket Edition or Bedrock (see [Cobblemon on Bedrock](/en/cobblemon-bedrock/)). What Coco Cobblemon has is **CocoLauncher Android** and [CocoLauncher iOS](#iphone-and-ipad), both still experimental. You play on the same server as people on PC.
{: .fs-5 .fw-300 }

[Download CocoLauncher-Android.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android.apk){: .btn .btn-primary }

## What your phone needs

6 GB of RAM or more (8 GB recommended), a mid-range chip and about 2 GB of free space. The first launch downloads about 400 MB, so use Wi-Fi. Weaker phones may still run it, but they tend to stutter or crash in busy areas.

## Install

1. Download [CocoLauncher-Android.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android.apk).
2. Open the file. If Android asks, allow your browser to install unknown apps.
3. Open CocoLauncher, enter a player name and press **Play**.

If a Chrome download gets stuck at 100%, pull down the notification shade. Chrome is waiting for you to confirm you want to keep the file.

The Android version uses a lighter pack, **Coco Lite**, but it still joins the same server.

## PC emulators (MuMu, LDPlayer)

Emulators need their own build: [CocoLauncher-Android-GiaLap.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android-GiaLap.apk). If your computer runs Windows, though, the [Windows launcher](/en/cocolauncher/) is lighter and more stable than an emulator.

## iPhone and iPad

There's an experimental **CocoLauncher iOS** build. Download it and follow the install guide on the [CocoLauncher iOS page](https://coconubs.github.io/CocoLauncher-iOS/) (in Vietnamese). iPhones can't install apps from outside the App Store directly, so setup takes longer than on Android:

- iPhone or iPad on iOS 14 or later, with at least 8 GB of RAM (iPhone 15 Pro, 16, 17).
- A Windows PC or Mac with a cable, used once for about 30 minutes of setup.
- An Apple ID (a secondary one is recommended). You'll need to refresh the app in SideStore every 7 days, or it won't open until you do.

The first start downloads about 1.5 GB, so use Wi-Fi. If you run into problems, ask on [Discord](https://discord.gg/hyspace) with a screenshot. More in [Cobblemon on iPhone and iPad](/en/cobblemon-ios/).

## Common problems

| Problem | Fix |
|---|---|
| Black screen or crash on start | If the renderer in Settings is on Auto, try LTW or Zink |
| Crashes after a while | Keep game memory at the recommended level and close other apps |
| Phone gets hot, game stutters | Lower the resolution to 50-70% and turn down the render distance |
| Emulator crashes | Use the emulator build, not the phone build |

Still stuck? Use the send-log button in the launcher settings and ask on [Discord](https://discord.gg/hyspace).

## Quick answers

### Where do I download the CocoLauncher APK?

Only from [Coconubs GitHub Releases](https://github.com/Coconubs/cocolauncher-pack/releases). It isn't on Google Play; the "Coco Launcher" app there is something else. Copies on other sites may have been tampered with.

### Can I use FCL or PojavLauncher instead?

We don't recommend it. With FCL or PojavLauncher you'd have to install all of the server's mods yourself, and it's easy to miss one. CocoLauncher Android does that for you.

### Can Minecraft PE play Cobblemon?

No. Cobblemon only runs on Java Edition. The "Cobblemon PE" packs you find online are add-ons made by other people, see [Cobblemon on Bedrock](/en/cobblemon-bedrock/).
