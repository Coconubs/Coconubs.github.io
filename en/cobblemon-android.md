# Play Cobblemon on Android and iPhone

Cobblemon is a mod for Minecraft Java Edition, so it does not install into Minecraft Pocket Edition or Bedrock. To play on a phone, the Coco Cobblemon server has **CocoLauncher Android**, an experimental app that runs Java Edition on the Android device and joins the same server as PC players. iPhone and iPad have a separate experimental build, [CocoLauncher iOS](#iphone-and-ipad).
{: .fs-5 .fw-300 }

[Download CocoLauncher-Android.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android.apk){: .btn .btn-primary }

## What your phone needs

- 6 GB of RAM or more, 8 GB or more recommended.
- A mid-range chip or better.
- About 2 GB of free storage.
- About 400 MB to download on first launch, so use Wi-Fi.

Weaker phones may still start the game, but they tend to stutter or close in busy areas.

## Install

1. Download [CocoLauncher-Android.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android.apk).
2. Open the file. If Android asks, allow your browser to install unknown apps.
3. Open CocoLauncher, enter a player name and press **Play**.

If a Chrome download sits at 100%, pull down the notification shade: Chrome is usually waiting for you to confirm keeping the .apk file.

The Android build uses the **Coco Lite** pack, about 125 mods. It is lighter than the PC pack and still joins the same server.

## PC emulators (MuMu, LDPlayer)

Emulators use a separate build: [CocoLauncher-Android-GiaLap.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android-GiaLap.apk). If the computer runs Windows, the [Windows launcher](/en/cocolauncher/) is lighter and more stable than an emulator.

## iPhone and iPad

There is an experimental **CocoLauncher iOS** build. Download it and follow the install guide on the [CocoLauncher iOS page](https://coconubs.github.io/CocoLauncher-iOS/) (in Vietnamese). iPhones cannot install apps from outside the App Store directly, so setup takes longer than on Android:

- iPhone or iPad on iOS 14 or later. 8 GB of RAM is recommended (iPhone 15 Pro, 16, 17); 6 GB devices run on the Low preset.
- A Windows PC or Mac with a cable, used once for about 30 minutes, to install SideStore and unlock more memory for the app.
- An Apple ID (a secondary one is recommended). Refresh the app in SideStore every 7 days, or it will not open until you do.

The first start downloads about 1.5 GB, so use Wi-Fi. For install problems or crashes, ask on [Discord](https://discord.gg/hyspace) with a screenshot and the `latestlog.txt` file.

Requirements, steps and quick answers for iPhone: see [Cobblemon on iPhone and iPad](/en/cobblemon-ios/).

## Common problems

| Problem | Fix |
|---|---|
| Black screen or crash on start | In Settings, if the renderer is on Auto, try LTW or Zink |
| Crashes after a while | Keep game memory at the recommended level and close other apps |
| Hot phone, stutter | Lower the resolution to 50-70% and the render distance |
| Emulator crashes | Use the emulator build, not the phone build |

Still stuck: use the send-log button in the launcher settings and ask on [Discord](https://discord.gg/hyspace).
