# How to join Coco Cobblemon

Download CocoLauncher, enter a name and press **Play**. The launcher sets everything up and takes you straight to the server, so there are no mods to install and no IP to type.
{: .fs-5 .fw-300 }

| Item | Details |
|---|---|
| **Server address (IP)** | `coco.ultramc.co` |
| **Version** | Minecraft Java 1.21.1, Cobblemon 1.7.3 |
| **Launcher** | [CocoLauncher](/en/cocolauncher/) |
| **Cost** | Free. Ranks and the Premium Battle Pass are optional |

## Step by step

1. **Download the launcher** for Windows, macOS, Android or iPhone from the [CocoLauncher page](/en/cocolauncher/).
2. **Enter a player name.** 3 to 16 characters: plain letters (no accents), numbers or underscores.
3. **Press Play.** The first launch takes a while, so use a stable connection. After that it only downloads what's changed.
4. **Register.** The game connects to the server on its own; just follow the sign-up screen.
5. **Open the menu.** Type `/menu`, or right-click the Menu item in the last hotbar slot. To switch it to English, click the VI/EN flag or type `/ngonngu en`.

## First day

1. Link your Discord (`/link` in game, then `/link <code>` on [Discord](https://discord.gg/hyspace)) to get daily check-in rewards.
2. Open the Battle Pass and do the 10 daily quests.
3. Pick up jobs with `/nghenghiep` to earn CobbleDollars.
4. Send your Pokémon on their 3 daily expeditions.
5. Climb the Battle Tower (`/battletower`) to earn BattleTower Points every day.
6. Claim land with `/claim` and set a home with `/sethome`. Build within ±30,000 blocks: past that you can't claim land, and the area resets every 2 weeks.

## How to join any Cobblemon server

Get the server's IP and mod list (usually from its Discord), install that modpack, then go to **Multiplayer**, press **Add Server** and paste the IP. If you get a mod mismatch error, your mods don't match the server's yet.

## Can I join with another launcher?

It's not recommended. The server runs its own set of mods, so with another launcher you'll likely be missing some and get turned away. If something goes wrong, see [Troubleshooting](/en/troubleshooting/).

## Bedrock or Pocket Edition?

No. Cobblemon only runs on Java Edition (see [Cobblemon on Bedrock and PE](/en/cobblemon-bedrock/)). On a phone, use CocoLauncher Android or CocoLauncher iOS. Both are still experimental. See [Play Cobblemon on Android and iPhone](/en/cobblemon-android/#iphone-and-ipad).
