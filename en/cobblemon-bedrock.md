# Cobblemon on Bedrock and Pocket Edition

The real Cobblemon mod only exists for Minecraft Java Edition, on Fabric or NeoForge. Anything called "Cobblemon PE", "Cobblemon Bedrock" or "Cobblemon MCPE" is a fan remake for Bedrock, not something the Cobblemon team released.
{: .fs-5 .fw-300 }

## Which Minecraft editions can run Cobblemon

| Minecraft edition | Official Cobblemon |
|---|---|
| Java Edition on Windows, macOS, Linux | Yes, with Fabric or NeoForge |
| Java Edition on Android, through a Java launcher | Yes, if the phone is strong enough |
| Bedrock, Pocket Edition (PE) on phones, Windows, consoles | No |

You can download Cobblemon from Modrinth and CurseForge. When we checked Modrinth on 11 November 2026, the latest release was Cobblemon 1.8.4 for Minecraft 1.21.1, out on 27 October 2026.

## What the "Cobblemon PE" add-ons are

MCPE add-on sites have plenty of packs with Cobblemon in the name. They're Bedrock add-ons inspired by Cobblemon:

- The Cobblemon team didn't make them. The Pokémon, menus and mechanics aren't the same as the Java mod.
- They can't join Java Cobblemon servers like Coco Cobblemon, because those servers need the actual mod on your side.
- Stick to sites you trust. Random add-on sites are often full of ads or fake downloads.

## Playing Cobblemon on a phone

To play the real thing on a phone, you run Minecraft Java Edition through a Java launcher:

- **Fold Craft Launcher (FCL), PojavLauncher:** run Java Edition on Android. You install Fabric and Cobblemon yourself, so it's good for solo play or any server you like.
- **CocoLauncher Android:** an experimental launcher just for joining Coco Cobblemon. It installs the Coco Lite pack (about 125 mods) for you and needs 6 GB of RAM or more, 8 GB recommended. See [Play Cobblemon on Android](/en/cobblemon-android/).

## Is there a Cobblemon server for PE players?

Cobblemon servers run on Java Edition, so the Minecraft PE app can't connect. If your Android phone can handle it, you can join Coco Cobblemon (`coco.ultramc.co`, Minecraft Java 1.21.1) with CocoLauncher Android and play alongside people on PC. Server details are on [Cobblemon server in Vietnam](/en/vietnam-cobblemon-server/).

## Quick answers

### Is Cobblemon on Bedrock?

No, it's Java Edition only. Bedrock or PE packs with the Cobblemon name are add-ons made by other people.

### Where can I download Cobblemon for Minecraft PE?

You can't. There's no official PE version, just unofficial add-ons that borrow the name.

### Can I join Coco Cobblemon from Minecraft PE?

No. Coco Cobblemon is a Minecraft Java 1.21.1 server with Cobblemon 1.7.3 and its own mod set, and you join it with CocoLauncher (download on the [CocoLauncher](/en/cocolauncher/) page).

### Does Minecraft PE have Pokémon?

There are a few fan-made Pokémon add-ons for Bedrock. Cobblemon and Pixelmon are Java Edition mods.
