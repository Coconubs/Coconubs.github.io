# Cobblemon on Bedrock and Pocket Edition

Short answer: official Cobblemon only exists for Minecraft Java Edition, running on Fabric or NeoForge. Packs called "Cobblemon PE", "Cobblemon Bedrock" or "Cobblemon MCPE" are add-ons that other people remade for Bedrock, not releases from the Cobblemon team.
{: .fs-5 .fw-300 }

## Which Minecraft editions run official Cobblemon

| Minecraft edition | Official Cobblemon |
|---|---|
| Java Edition on Windows, macOS, Linux | Yes, through Fabric or NeoForge |
| Java Edition on Android, through a Java launcher | Runs if the device is powerful enough |
| Bedrock, Pocket Edition (PE) on phones, Windows, consoles | No |

Cobblemon downloads are on Modrinth and CurseForge. On Modrinth, the newest release when this page was written is Cobblemon 1.8.4 for Minecraft 1.21.1, released on 27 October 2026.

## What "Cobblemon PE" add-ons are

Minecraft PE add-on sites list many packs named Cobblemon. They are Bedrock add-ons based on the idea of Cobblemon:

- They are not made by the Cobblemon team. Pokémon, menus and mechanics differ from the Java mod.
- They cannot join Cobblemon servers that run on Java Edition, such as Coco Cobblemon, because a Java server needs the actual Cobblemon mod on the player's side.
- Only download from sites you trust. Unknown add-on sites often bundle ads or fake files.

## Playing Cobblemon on a phone

The way to play real Cobblemon on a phone is to run Minecraft Java Edition through a Java launcher:

- **Fold Craft Launcher (FCL), PojavLauncher:** run Java Edition on Android; you install Fabric and Cobblemon yourself. Good for playing alone or joining a server of your choice.
- **CocoLauncher Android:** an experimental build made only for joining the Coco Cobblemon server. It installs the Coco Lite pack (about 125 mods) for you and needs 6 GB of RAM or more, 8 GB or more recommended. See [Play Cobblemon on Android](/en/cobblemon-android/).

## Is there a Cobblemon server for PE players?

Cobblemon servers run Java Edition, so the Minecraft PE app cannot join them. If an Android phone is powerful enough, players can join Coco Cobblemon (`coco.ultramc.co`, Minecraft Java 1.21.1) with CocoLauncher Android and play together with PC players. Server details are on the [Cobblemon server in Vietnam](/en/vietnam-cobblemon-server/) page.

## Quick answers

### Is Cobblemon on Bedrock?

No. Cobblemon is a mod for Minecraft Java Edition only. Packs named Cobblemon for Bedrock or PE are add-ons made by other people, not Cobblemon.

### Where can I download Cobblemon for Minecraft PE?

There is no official PE version. Packs named Cobblemon for PE are other people's add-ons, not the Cobblemon mod.

### Can Cobblemon PE join the Coco Cobblemon server?

No. Coco Cobblemon is a Minecraft Java 1.21.1 server running Cobblemon 1.7.3 with its own mod set, joined with CocoLauncher on Windows, macOS or Android.

### Does Minecraft PE have Pokémon?

There are a few community-made Pokémon add-ons for Bedrock. Cobblemon and Pixelmon are mods for Java Edition.
