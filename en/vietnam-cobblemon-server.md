# Cobblemon server in Vietnam: Coco Cobblemon

Coco Cobblemon is a Vietnamese community Minecraft Java server running the Cobblemon mod, played through its own launcher, CocoLauncher. This page is for players looking for a Cobblemon server in Vietnam: server details, ping, player numbers with the date they were measured, the weekly schedule in Vietnam time and what to check before you pick a server.

## Can I join from outside Vietnam?

Yes. Anyone with CocoLauncher can join. The server is in Singapore, so ping is lowest from Southeast Asia and higher from Europe or America. Most players and most of the chat are Vietnamese.

## How to join

1. Download CocoLauncher from the [CocoLauncher page](/en/cocolauncher/).
2. Enter a player name and press **Play**. The launcher installs Java, Minecraft, Fabric and the server's mod set.
3. In game, type `/menu` for the guide and `/ngonngu en` for English.

The latest Cobblemon Official Modpack (Cobblemon 1.8) cannot join, because the server runs Cobblemon 1.7.3 with its own mods. Details in [How to join](/en/how-to-join/) and [Which launcher for Cobblemon](/en/cobblemon-launcher/).
