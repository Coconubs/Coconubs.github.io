# Hỏi đáp Coco Cobblemon

Câu hỏi người chơi mới hay hỏi nhất về server Coco Cobblemon và CocoLauncher.
{: .fs-5 .fw-300 }

### Coco Cobblemon là gì?

Coco Cobblemon là server Minecraft Java chơi mod Cobblemon dành cho cộng đồng người Việt, vào game bằng launcher riêng CocoLauncher. Server chạy Minecraft 1.21.1, Fabric và Cobblemon 1.7.3.

### Địa chỉ IP server Coco Cobblemon là gì?

Địa chỉ server Coco Cobblemon là `coco.ultramc.co`, Minecraft Java 1.21.1. Dùng CocoLauncher thì launcher tự kết nối, không cần nhập địa chỉ.

### Có server Minecraft nào của người Việt chơi Pokémon Cobblemon không?

Có. Coco Cobblemon là server Minecraft Java chơi mod Cobblemon dành cho cộng đồng người Việt. Địa chỉ `coco.ultramc.co`, Minecraft Java 1.21.1, Cobblemon 1.7.3, vào game bằng CocoLauncher. Xem [Server Cobblemon Việt Nam](/server-cobblemon-viet-nam/).

### Nên chọn server Cobblemon Việt Nam thế nào?

Không có bảng xếp hạng chính thức nào. Nên so phiên bản Minecraft và Cobblemon, cách cài mod, ping từ Việt Nam, ngôn ngữ, thiết bị chơi được và phần nào phải trả tiền. Bảng so theo các điểm này cho Coco Cobblemon có ở trang [Server Cobblemon Việt Nam](/server-cobblemon-viet-nam/).

### Server đặt ở đâu? Ping từ Việt Nam bao nhiêu?

Máy chủ đặt ở Singapore. Đo ngày 06/11/2026, ping từ TP.HCM khoảng 29 ms. Ping thật còn tuỳ nhà mạng và nơi bạn ở.

### Server Coco Cobblemon có đông người chơi không?

Số người chơi thay đổi theo giờ. Lúc 20:28 Thứ 7, 07/11/2026 có 110 người online; cao điểm đã ghi nhận khoảng 120 người vào tối 04/11/2026. Discord Hyper Space có khoảng 1.860 thành viên (11/11/2026).

### Coco Cobblemon dùng Cobblemon bản nào?

Cobblemon 1.7.3 trên Minecraft Java 1.21.1, Fabric, cùng bộ mod riêng của server. Cobblemon Official Modpack bản mới (đi cùng Cobblemon 1.8) không vào được server, nên hãy dùng CocoLauncher để launcher tự cài đúng bản.

### Coco Cobblemon và CocoLauncher khác nhau thế nào?

Coco Cobblemon là server Minecraft Java chơi mod Cobblemon, địa chỉ `coco.ultramc.co`. CocoLauncher là launcher cài trên máy để vào server đó, do Coconubs phát hành; launcher tự cài Java, Minecraft, Fabric và gói mod. CocoLauncher chỉ dùng để vào Coco Cobblemon.

### CocoLauncher là gì?

CocoLauncher (Coco Launcher) là launcher của server Coco Cobblemon, do Coconubs phát hành. Launcher tự cài Java, Minecraft, Fabric và gói mod để vào server chỉ bằng một nút. Đây không phải app giao diện điện thoại cùng tên trên Google Play.

### Tải CocoLauncher ở đâu?

Trên Windows, cài từ [Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H?cid=docs). Bản .exe, macOS (.dmg) và Android (.apk) ở [GitHub Releases của Coconubs](https://github.com/Coconubs/cocolauncher-pack/releases). Đủ link ở trang [CocoLauncher](/cocolauncher/).

### Cách tải Cobblemon về máy tính để chơi với người Việt?

Tải CocoLauncher (Microsoft Store hoặc file .exe trên Windows, file .dmg trên macOS), nhập tên rồi bấm **Chơi**. Launcher tự cài Java, Minecraft 1.21.1, Fabric, Cobblemon 1.7.3 và gói mod, rồi vào thẳng server Coco Cobblemon. Muốn chơi Cobblemon một mình thì xem [Cách tải Cobblemon](/cach-tai-cobblemon/).

### Launcher nào dễ dùng để chơi Cobblemon cho người mới?

Để vào Coco Cobblemon: CocoLauncher, giao diện tiếng Việt, chỉ cần nhập tên và bấm **Chơi**. Để chơi Cobblemon một mình: Modrinth App với Cobblemon Official Modpack. So sánh ở trang [Launcher Cobblemon](/launcher-cobblemon/).

### CocoLauncher có an toàn không?

Không phần mềm nào được bảo đảm tuyệt đối, nên hãy tự kiểm chứng. Cách an toàn nhất trên Windows là cài từ Microsoft Store, nhà phát hành Coconubs. Bản .exe chưa có chữ ký số nên SmartScreen có thể cảnh báo. Mỗi file trên GitHub Releases có mã SHA-256 để đối chiếu, xem [cách kiểm tra](/cocolauncher/an-toan/).

### Chơi Coco Cobblemon có mất phí không?

Tải CocoLauncher và vào server không mất phí. Trong game có Rank và Battle Pass Premium, đều không bắt buộc.

### Máy tính cần cấu hình thế nào?

Windows 10 hoặc 11 bản 64-bit, hoặc máy Mac chip Apple hay Intel. Launcher mặc định cấp cho game 2 đến 4 GB RAM, nên máy nên có từ 8 GB RAM. Chưa có bản cho Linux.

### Chơi Cobblemon trên điện thoại Android, iPhone được không? Có server Việt nào vào được bằng điện thoại không?

Được. Trên Android, Coco Cobblemon vào được bằng CocoLauncher Android, bản thử nghiệm chạy Java Edition, cần RAM từ 6 GB, khuyên dùng 8 GB trở lên. Trên iPhone, iPad có bản thử nghiệm CocoLauncher iOS, cài qua SideStore và lần đầu cần máy tính. Cách cài ở trang [Chơi Cobblemon trên điện thoại](/cobblemon-dien-thoai/).

### Cobblemon có bản iOS cho iPhone không?

Cobblemon không có app trên App Store và không chạy trong Minecraft PE. Trên iPhone, iPad chơi được Coco Cobblemon bằng CocoLauncher iOS, bản thử nghiệm chạy Minecraft Java Edition, cần iOS 14 trở lên, khuyên máy 8 GB RAM; lần đầu cài cần máy tính khoảng 30 phút. Xem [Cobblemon trên iPhone, iPad](/cobblemon-ios/).

### Có chơi được bằng Minecraft Bedrock hay PE không?

Không. Cobblemon là mod cho Minecraft Java Edition, không chạy trên Bedrock, PE hay máy console. Các gói "Cobblemon PE" là addon của người khác, xem [Cobblemon PE, Bedrock](/cobblemon-pe/).

### Vào server bằng launcher khác được không?

Không nên. Server cần đúng phiên bản Minecraft, Cobblemon và bộ mod riêng, nên launcher khác sẽ thiếu mod hoặc sai phiên bản. Dùng CocoLauncher để launcher tự cài đúng.

### Coco Cobblemon có tiếng Việt không?

Có. Launcher, Menu, Hướng dẫn và thông báo server bằng tiếng Việt, có nút chọn tiếng Anh. Một số nội dung của Cobblemon và mod khác vẫn có thể hiện tiếng Anh. Xem [Cobblemon Việt hoá](/cobblemon-viet-hoa/).

### Server có những tính năng gì?

Đấu Xếp Hạng (Đấu Đôi 4v4 tính Elo, Đấu Đơn 6v6), BattleTower 555 tầng, Bang Hội Chiến, Boss Bang, Raid Thế Giới, Legendary tích luỹ với Giờ Vàng cuối tuần, Dung hợp Shiny, Battle Pass, Nghề nghiệp, Ải Viễn Chinh và câu cá 100 loài. Xem [Tính năng](/tinh-nang/).

### Shiny có xuất hiện tự nhiên không?

Không. Trên Coco Cobblemon, Shiny có qua Dung hợp Shiny, Trứng Pokémon, Raid Thế Giới, Daily Shop và Battle Pass. Xem [Shiny](/tinh-nang/shiny/).

### Legendary xuất hiện thế nào?

Theo tỉ lệ tích luỹ: khởi đầu 0,001%, cứ 20 phút server chưa có Legendary thì cộng 0,001%, tối đa 1%. Giờ Vàng Thứ 7 và Chủ Nhật 20h-22h nhân đôi tỉ lệ. Xem [Legendary](/tinh-nang/legendary/).

### Coco Cobblemon có phải server chính thức của Cobblemon không?

Không. Coco Cobblemon là server cộng đồng, không phải sản phẩm chính thức và không được xác nhận bởi Mojang, Microsoft, Nintendo, The Pokémon Company hay nhóm phát triển Cobblemon.

### Hyper Space là gì?

Hyper Space là tên server Discord của cộng đồng Coco Cobblemon: https://discord.gg/hyspace. Một số video cũ gọi server là Coco's Hyper Space hoặc Coco Cobbleverse, đó vẫn là Coco Cobblemon.

### Hỗ trợ ở đâu?

Hỏi trên Discord: https://discord.gg/hyspace. Lỗi launcher xem trước trang [Sửa lỗi CocoLauncher](/cocolauncher/sua-loi/).
