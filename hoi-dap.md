# Hỏi đáp Coco Cobblemon

Những câu người mới hay hỏi về server và CocoLauncher.
{: .fs-5 .fw-300 }

## Về server Coco Cobblemon

### Coco Cobblemon là gì?

Coco Cobblemon là server Minecraft của người Việt, chơi mod Pokémon Cobblemon. Server chạy Minecraft Java 1.21.1 với Cobblemon 1.7.3, vào chơi bằng launcher riêng là CocoLauncher.

### IP server Coco Cobblemon là gì?

IP là `coco.ultramc.co`, Minecraft Java 1.21.1. Nếu dùng CocoLauncher thì không cần nhập, launcher tự vào server.

### Có server Cobblemon nào của người Việt không?

Có, Coco Cobblemon là một server như vậy. IP `coco.ultramc.co`, Cobblemon 1.7.3, vào bằng CocoLauncher. Xem thêm ở trang [Server Cobblemon Việt Nam](/server-cobblemon-viet-nam/).

### Chọn server Cobblemon Việt Nam thế nào?

Không có bảng xếp hạng chính thức nào cả. Bạn nên xem server dùng bản Minecraft và Cobblemon nào, cài mod có dễ không, có tiếng Việt không, chơi được trên máy nào và cái gì phải trả tiền. Coco Cobblemon được so theo từng điểm này ở trang [Server Cobblemon Việt Nam](/server-cobblemon-viet-nam/).

### Server có đông người chơi không?

Số người online tuỳ giờ. Lúc 20:28 Thứ 7, 07/11/2026 có 110 người online; cao điểm từng ghi nhận khoảng 120 người vào tối 04/11/2026. Discord Hyper Space có khoảng 1.860 thành viên (11/11/2026).

### Server dùng Cobblemon bản nào?

Cobblemon 1.7.3 trên Minecraft Java 1.21.1 (Fabric), kèm bộ mod riêng của server. Cobblemon Official Modpack bản mới (đi cùng Cobblemon 1.8) không vào được, nên cứ dùng CocoLauncher cho đúng bản.

## CocoLauncher và cách tải

### CocoLauncher là gì?

CocoLauncher (Coco Launcher) là launcher để vào server Coco Cobblemon, do Coconubs làm. Bạn chỉ cần nhập tên và bấm Chơi, launcher tự cài hết rồi vào thẳng server. Launcher này chỉ dùng cho Coco Cobblemon, và không phải app giao diện điện thoại cùng tên trên Google Play.

### Tải CocoLauncher ở đâu?

Trên Windows thì cài từ [Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H?cid=docs). Bản .exe, bản macOS (.dmg) và Android (.apk) có ở [GitHub Releases của Coconubs](https://github.com/Coconubs/cocolauncher-pack/releases). Đủ link ở trang [CocoLauncher](/cocolauncher/).

### Tải Cobblemon về máy tính thế nào để chơi cùng người Việt?

Tải CocoLauncher (Microsoft Store hoặc file .exe trên Windows, file .dmg trên macOS), nhập tên rồi bấm **Chơi**. Launcher tự cài Minecraft 1.21.1, Cobblemon 1.7.3 và các mod cần thiết, xong là vào server luôn. Nếu muốn chơi Cobblemon một mình thì xem [Cách tải Cobblemon](/cach-tai-cobblemon/).

### Người mới nên dùng launcher nào để chơi Cobblemon?

Muốn vào Coco Cobblemon thì dùng CocoLauncher: giao diện tiếng Việt, nhập tên là chơi. Muốn chơi một mình thì dùng Modrinth App với Cobblemon Official Modpack. So sánh kỹ hơn ở trang [Launcher Cobblemon](/launcher-cobblemon/).

### CocoLauncher có an toàn không?

Không phần mềm nào an toàn tuyệt đối, nên bạn cứ tự kiểm tra. Trên Windows, cài từ Microsoft Store (nhà phát hành Coconubs) là chắc nhất. Bản .exe chưa có chữ ký số nên SmartScreen có thể hiện cảnh báo. Mỗi file trên GitHub Releases đều kèm mã SHA-256 để bạn đối chiếu, xem [cách kiểm tra](/cocolauncher/an-toan/).

## Chi phí và cấu hình máy

### Chơi có mất tiền không?

Không. Tải CocoLauncher và vào server đều miễn phí. Trong game có Rank và Battle Pass Premium, mua hay không tuỳ bạn.

### Máy tính cần cấu hình thế nào?

Windows 10 hoặc 11 bản 64-bit, hoặc máy Mac chip Apple hay Intel. Launcher mặc định cho game dùng 2 đến 4 GB RAM, nên máy có từ 8 GB RAM là ổn. Chưa có bản cho Linux.

## Điện thoại, Bedrock và launcher khác

### Chơi Cobblemon trên điện thoại được không?

Được. Android có CocoLauncher Android, bản thử nghiệm chạy Java Edition, cần RAM từ 6 GB, tốt nhất từ 8 GB. iPhone, iPad có CocoLauncher iOS, cũng đang thử nghiệm, cài qua SideStore và lần đầu cần máy tính. Cách cài ở trang [Chơi Cobblemon trên điện thoại](/cobblemon-dien-thoai/).

### Cobblemon có bản cho iPhone không?

Cobblemon không có trên App Store và không chạy trong Minecraft PE. Muốn chơi Coco Cobblemon trên iPhone, iPad thì dùng CocoLauncher iOS (bản thử nghiệm, chạy Minecraft Java Edition), cần iOS 14 trở lên, nên dùng máy 8 GB RAM. Lần cài đầu cần máy tính, mất khoảng 30 phút. Xem [Cobblemon trên iPhone, iPad](/cobblemon-ios/).

### Chơi bằng Minecraft Bedrock hay PE được không?

Không. Cobblemon là mod cho Java Edition, không chạy trên Bedrock, PE hay máy console, nên Coco Cobblemon cũng chỉ vào được bằng Java Edition. Mấy gói "Cobblemon PE" là addon của người khác làm, xem [Cobblemon PE, Bedrock](/cobblemon-pe/).

### Vào server bằng launcher khác được không?

Không nên. Server cần đúng bản Minecraft, Cobblemon và bộ mod riêng, launcher khác sẽ thiếu mod hoặc sai bản. Cứ dùng CocoLauncher, nó tự cài đúng.

## Tiếng Việt và tính năng

### Server có tiếng Việt không?

Có. Launcher, Menu, Hướng dẫn và thông báo của server đều tiếng Việt, có nút đổi sang tiếng Anh. Tên Pokémon và chiêu thức trong trận theo ngôn ngữ bạn chọn trong Minecraft; Cobblemon 1.7.3 mới dịch sẵn khoảng 60% (kiểm kê 01/11/2026), nên vẫn còn chỗ hiện tiếng Anh. Xem [Cobblemon Việt hoá](/cobblemon-viet-hoa/).

### Server có những gì để chơi?

Đấu Xếp Hạng (Đấu Đôi 4v4 tính Elo, Đấu Đơn 6v6), BattleTower 555 tầng, Bang Hội Chiến, Boss Bang, Raid Thế Giới, Legendary tích luỹ với Giờ Vàng cuối tuần, Dung hợp Shiny, Battle Pass, Nghề nghiệp, Ải Viễn Chinh và câu cá 100 loài. Xem [Tính năng](/tinh-nang/).

### Shiny có ra ngoài tự nhiên không?

Không. Shiny chỉ có qua Dung hợp Shiny, Trứng Pokémon, Raid Thế Giới, Daily Shop và Battle Pass. Xem [Shiny](/tinh-nang/shiny/).

### Legendary ra thế nào?

Tỉ lệ cộng dồn: bắt đầu 0,001%, cứ 20 phút server chưa có Legendary thì cộng thêm 0,001%, tối đa 1%. Giờ Vàng Thứ 7 và Chủ Nhật 20h-22h tỉ lệ nhân đôi. Xem [Legendary](/tinh-nang/legendary/).

### Có tiến hoá Mega không?

Có, server dùng mod Mega Showdown. Đeo Mega Bracelet, cho Pokémon cầm đúng đá Mega của nó (mua ở Shop Tokens), vào trận rồi bấm nút Mega. Mỗi lúc bạn chỉ có 1 con ở dạng Mega. Xem [Cách tiến hoá Mega](/mega-cobblemon/).

### Cưỡi Pokémon được không?

Được. Thả Pokémon ra, giữ Shift, bấm chuột phải vào nó rồi chọn Lái. Cobblemon 1.7.3 có 84 loài cưỡi được, server thêm vài loài nữa như Zacian, Zamazenta, Rayquaza, và cưỡi trên server không tốn thể lực. Xem [Cách cưỡi Pokémon](/cuoi-pokemon-cobblemon/).

## Discord và hỗ trợ

### Coco Cobblemon có phải server chính thức của Cobblemon không?

Không. Đây là server cộng đồng, không phải sản phẩm chính thức và không được Mojang, Microsoft, Nintendo, The Pokémon Company hay nhóm làm Cobblemon xác nhận.

### Hyper Space là gì?

Hyper Space là tên server Discord của cộng đồng Coco Cobblemon: https://discord.gg/hyspace. Vài video cũ gọi server là Coco's Hyper Space hoặc Coco Cobbleverse, đều là Coco Cobblemon cả.

### Cần giúp thì hỏi ở đâu?
