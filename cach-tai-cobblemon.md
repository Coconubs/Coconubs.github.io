# Cách tải Cobblemon cho Minecraft Java

Hai cách tuỳ theo bạn muốn vào server người Việt hay tự chơi bản gốc.

> **Lưu ý trước khi tải:** Cobblemon là mod cho Minecraft **Java Edition**, không chạy trên Bedrock. Mỗi server cần đúng phiên bản: tại ngày 01/11/2026 Modrinth có bản Fabric 1.8.4F, còn server Coco Cobblemon dùng **1.7.3**. Bản mới hơn có thể đã ra, hãy kiểm tra trên Modrinth.

## Cách 1: dùng CocoLauncher

Nhanh nhất nếu bạn muốn chơi cùng người Việt: launcher lo hết phiên bản và mod. Xem [các bước vào server](/cach-vao-server/).

## Cách 2: tự cài Cobblemon bản gốc

Dành cho chơi một mình hoặc server riêng. Bản này không vào được server Coco Cobblemon vì khác phiên bản và thiếu gói mod.

1. Cài [Modrinth App](https://modrinth.com/app).
2. Tìm **Cobblemon Official Modpack** trong tab Modpacks, chọn bản Fabric, bấm Install. App tự tải đúng Minecraft, Fabric và mod phụ thuộc.
3. Trong cài đặt instance, tăng RAM nếu game chậm, rồi bấm Play.

Cũng có thể tải riêng mod tại [trang Cobblemon trên Modrinth](https://modrinth.com/mod/cobblemon), nhưng phải tự cài Fabric Loader, Fabric API và Fabric Language Kotlin. So sánh các launcher ở trang [Launcher nào để chơi Cobblemon](/launcher-cobblemon/).

## Lỗi hay gặp

- **Sai phiên bản khi vào server:** client và server phải cùng bản Minecraft, Cobblemon và bộ mod bắt buộc.
- **Game văng lúc khởi động:** kiểm tra Java tương thích và RAM cấp cho game. CocoLauncher tự kèm Java.
- **Điện thoại:** bản Android của CocoLauncher là bản thử nghiệm, xem [yêu cầu cấu hình](/cobblemon-dien-thoai/).
